# GOR Browser v1.2 — патч с новыми функциями

## Что внутри

Новые модули (кладутся в `GOR_Brauzer/`, рядом с `browser_widget.py`):

- `browser_adblock.py` — AdBlock (uBlock Engine): сетевой интерцептор
  `QWebEngineUrlRequestInterceptor` + косметический JS-фильтр.
- `browser_translate.py` — VOT Engine: нативная инъекция `vot.user.js`
  через `QWebEngineScript` (без Tampermonkey).
- `browser_groups.py` — сохраняемые группы вкладок (цвета, единое окно
  редактирования, автосохранение в `games_data.json`), индикатор «● Открыта»
  для группы, все вкладки которой сейчас открыты в браузере, плюс
  `GroupedTabBar` — визуальная группировка прямо в ленте вкладок (цветная
  полоска под вкладками одной группы, как в Firefox/Chrome).
- `browser_broadcast.py` — Real-Time LAN Broadcast: отправка вкладки/группы
  по UDP, приём с уведомлением («Открыть все» / «Сохранить в JSON»).

Изменённые файлы (заменяют существующие):

- `browser_constants.py` — добавлены новые ключи настроек и константы.
- `browser_widget.py` — подключение всех новых модулей: интерцептор ставится
  на профиль в `__init__`, добавлена вкладка «Группы» в сайдбар, кнопка
  📡 в тулбаре, обработчик входящих broadcast-пакетов.
- `browser_dialogs.py` — новая вкладка настроек «🛡️ Безопасность и сеть»
  (переключатели AdBlock/VOT/Broadcast, поле UDP-порта), плюс полный
  визуальный редизайн всего окна настроек: карточки-секции вместо плоских
  подписей, боковое меню разделов вместо вкладок, современные чекбоксы
  и поля с фокус-эффектом, аккуратные кнопки с hover-состояниями.

## Установка

1. Сделай резервную копию текущей папки `GOR_Brauzer/` (на всякий случай).
2. Скопируй все файлы из этого патча в `GOR_Brauzer/`, подтвердив замену
   существующих `browser_constants.py`, `browser_widget.py`, `browser_dialogs.py`.
3. Запусти лаунчер как обычно — новые настройки (`adblock_enabled` и т.д.)
   подставятся автоматически из `DEFAULT_SETTINGS` при первом запуске.

## Как проверить, что всё работает

- **AdBlock**: открой любой сайт с рекламой — сетевые запросы к доменам из
  `BLOCKED_DOMAINS` (в `browser_adblock.py`) будут резаться. Список легко
  дополнить — либо прямо в файле, либо положив рядом с браузером файл
  `adblock_domains.txt` (по домену на строку).
- **VOT-переводчик**: кнопка «🌐 Перевести видео» появляется поверх любого
  `<video>` на странице. Чтобы включить реальный перевод (а не заглушку),
  положи файл `vot.user.js` (скачанный с официального репозитория проекта
  Voice-Over-Translation) рядом с `settings.json` браузера — движок сам
  его подхватит и внедрит через `QWebEngineScript`.
- **Живая группировка в ленте вкладок (как в Firefox/Chrome)**: когда
  открываешь сохранённую группу (двойной клик в сайдбаре) — её вкладки
  сразу подсвечиваются цветной полоской под текстом, как подчёркивание
  группы в Firefox. Правый клик по любой сгруппированной вкладке даёт
  «🙈 Свернуть группу» (скрывает остальные вкладки группы, оставляя одну
  «шляпку» с именем и счётчиком — клик разворачивает обратно) и «➖ Убрать
  вкладку из группы». Правый клик по обычной вкладке даёт «➕ Добавить в
  группу» (список существующих) или «🆕 Новая группа из этой вкладки...»
  — как «Add tab to new group» в Firefox/Chrome, только результат сразу
  сохраняется в JSON, а не живёт только пока открыто окно.
- **LAN Broadcast**: кнопка 📡 в тулбаре отправляет активную вкладку всем
  GOR Browser в локальной сети (UDP-порт 51888 по умолчанию, настраивается
  в «⚙️ Настройки → 🛡️ Безопасность и сеть»). Группу целиком можно отправить
  через правый клик по ней в сайдбаре → «📡 Отправить группу в сеть».
  На принимающей стороне появится всплывающее окно с кнопками «Открыть все»
  / «Сохранить в JSON».

## Важный нюанс по VOT

Сам движок распознавания речи/перевода (`vot.user.js`) — это отдельный
открытый проект (voice-over-translation на GitHub), а не код, написанный
внутри этого патча: я не реверсил и не переизобретал его закрытые API
перевода. Патч даёт именно то, что описано в release notes — «нативную
интеграцию скрипта через QWebEngineScript» — то есть механизм внедрения.
Без положенного рядом `vot.user.js` кнопка перевода будет видна, но честно
покажет, что движок не установлен, вместо того чтобы притворяться рабочей.

Все остальные три фичи (AdBlock, группы вкладок, LAN Broadcast) реализованы
полностью и самодостаточно — сторонних скриптов не требуют.
