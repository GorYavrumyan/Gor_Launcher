## Реализованные пункты ТЗ

**2. Общий буфер обмена по LAN**
Новый тип UDP-пакета `"clipboard"` поверх существующей LAN Broadcast
инфраструктуры (тот же протокол, что и «отправить вкладку»). Браузер
слушает системный буфер обмена (`QApplication.clipboard().dataChanged`) —
если фича включена, любое скопированное вами значение уходит в сеть, и
наоборот, скопированное на другом ПК подставляется в ваш буфер обмена.
Защита от зацикливания (получил → сам себе не переслал обратно) сделана
через флаг подавления на время программной записи в буфер.

⚠️ **Выключено по умолчанию** — буфер обмена нередко содержит пароли,
токены, личные данные, поэтому это осознанный opt-in с обеих сторон, а не
поведение "из коробки". Включается через меню ⋮ → «📋 Общий буфер обмена по
LAN» (нужно включить на всех устройствах, где это нужно).

**2. Синхронизация закладок по LAN**
Новый тип пакета `"bookmark_sync"` — при добавлении/редактировании закладки
(если фича включена) в сеть уходит ПОЛНЫЙ текущий список закладок. Получатели
добавляют себе только те, которых у них ещё нет (merge по URL) — существующие
локальные закладки не перезаписываются и не удаляются (удаление закладки
намеренно НЕ рассылается, иначе удаление у одного стёрло бы её у всех).
Тоже выключено по умолчанию, включается через меню ⋮ → «🔗 Синхронизация
закладок по LAN». Там же — «Отправить свои закладки в сеть сейчас» для
разовой ручной синхронизации (без ожидания следующего изменения).

Оба переключателя и статусы — во всплывающем меню ⋮ (там же, где теперь и
настройки Tab Suspender из патча 2/4).

## Установка

Скопируйте 3 файла поверх существующих. Новые ключи настроек
(`lan_clipboard_enabled`, `lan_bookmark_sync_enabled`) появятся сами при
первом сохранении, ничего мигрировать вручную не нужно.

## Как проверить

- **Буфер обмена**: на двух ПК (или двух процессах на одном ПК — работает
  благодаря фиксу loopback из патча 1/4) включить «📋 Общий буфер обмена по
  LAN» в обоих. Скопировать текст на одном → через секунду он окажется в
  буфере обмена на другом (проверить вставкой куда угодно). Статус-строка в
  заголовке окна покажет источник и превью текста.
- **Закладки**: включить «🔗 Синхронизация закладок по LAN» на двух
  устройствах, добавить закладку на одном — на втором она появится в
  сайдбаре «Закладки» с уведомлением "+1 новых от ...". Либо нажать
  «Отправить свои закладки в сеть сейчас» для мгновенной разовой отправки
  всего текущего списка.
