# GOR Launcher — система аккаунтов (патч)

## Что делает

При запуске лаунчера сначала открывается окно выбора/создания аккаунта.
После выбора аккаунта лаунчер открывается уже "под ним" — и всё, что он
пишет (`games_data.json`, профиль браузера `core/GOR_Profile`, папка
`addons`), физически хранится в:

```
accounts/
  Vova/
    games_data.json
    GOR_Profile/
    addons/
  Katya/
    games_data.json
    GOR_Profile/
    addons/
  accounts_index.json   <- список аккаунтов + хэши паролей (если заданы)
```

## Как это работает технически

Ни один из существующих файлов лаунчера (`GorLauncher.py`, `browser_tab.py`,
`bridge_loader.py`, `ControlCenter.py` и т.д.) НЕ пришлось переписывать —
они как читали `games_data.json` / `GOR_Profile` / `addons` по старым
путям, так и продолжают это делать. Модуль `shared/account_manager.py`
в момент выбора аккаунта подменяет эти пути на уровне файловой системы:

- `games_data.json` (корень проекта) → жёсткая ссылка (hardlink,
  `mklink /H`) на `accounts/<имя>/games_data.json`
- `core/GOR_Profile` → junction (`mklink /J`) на `accounts/<имя>/GOR_Profile`
- `addons` (корень проекта) → junction на `accounts/<имя>/addons`

И junction, и hardlink — особенность NTFS, которая НЕ требует прав
администратора и НЕ требует включённого "Режима разработчика" в Windows
(в отличие от обычных симлинков). Если по какой-то причине они не
создаются (например, диск не NTFS) — модуль тихо переключается на обычное
копирование, чтобы лаунчер всё равно запустился (см. комментарии в коде).

При первом запуске патча твои текущие `games_data.json` / `GOR_Profile` /
`addons` автоматически "усыновляются" первым созданным аккаунтом — никто
не теряет свою библиотеку игр.

## Установка

1. Сделай бэкап папки лаунчера на всякий случай.
2. Скопируй `shared/account_manager.py` и `shared/account_dialog.py` в
   папку `shared/` проекта (это новые файлы).
3. Замени `bridge_loader.py` в корне проекта на файл из этого патча
   (в него добавлен только блок выбора аккаунта перед открытием окна
   лаунчера — остальной код не менялся).
4. Запусти лаунчер как обычно:
   ```
   runtime\python.exe bridge_loader.py
   ```

## Как пользоваться

- При первом запуске появится форма "Новый аккаунт" — введи имя, при
  желании нажми на кружок сверху и выбери картинку-обложку, пароль
  необязателен, затем «Создать и войти». Твои текущие игры/браузер/аддоны
  автоматически станут этим аккаунтом.
- При следующих запусках откроется список аккаунтов (с обложками): выбери
  нужный, нажми «Войти» (если у аккаунта есть пароль — попросит его ввести).
- Кнопка «➕ Новый аккаунт» создаёт ещё один — с чистой библиотекой игр,
  своим браузером (свои куки/пароли/история) и своей папкой аддонов.
- Кнопка «🗑 Удалить»: если у аккаунта есть пароль — попросит его ввести
  (это и есть подтверждение удаления); если пароля нет — обычное окно
  «точно удалить?». Нельзя удалить тот аккаунт, который сейчас активен.
- **Внутри уже открытого лаунчера**, в самом левом углу верхней панели
  (перед надписью «Всего игр: ...») — круглая кнопка с твоей обложкой. Клик по ней открывает окно «мой
  аккаунт»: большая обложка + имя сверху (там же можно сменить обложку
  в любой момент кнопкой «🖼 Сменить обложку»), ниже — список остальных
  аккаунтов (обложка + имя). Выбери аккаунт → «Переключиться →» → если
  у него есть пароль, спросит пароль → спросит подтверждение перезапуска
  → лаунчер перезапускается уже под выбранным аккаунтом, без повторного
  показа окна выбора (оно там просто не нужно — ты уже выбрал).

## Важные нюансы

- Кнопка «🔄 Перезапуск» в лаунчере тоже возвращает на экран выбора
  аккаунта при каждом рестарте — это осознанно, чтобы можно было
  переключиться на другой аккаунт в одно действие.
- Пароль аккаунта хранится как SHA-256 хэш с солью в `accounts_index.json`
  — это удобная защита от случайного захода не под своим аккаунтом на
  общем ПК, а не криптостойкая защита от целенаправленного взлома.
- Игры, которые лежат в общих местах на диске (сами .exe игр по путям в
  `games_data.json`) — не копируются и не изолируются, изолируется только
  сама библиотека/список/настройки/браузер/аддоны лаунчера. Это и
  ожидалось: у каждого аккаунта своя "витрина", но файлы игр общие для ПК.
