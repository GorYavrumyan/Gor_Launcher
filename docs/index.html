КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ

Управление Библиотекой Игр

Организация по группам и папкам, гибкие аргументы запуска, мониторинг процесса ProcessMonitor и удобные сортировки.

Встроенный Браузер GOR_Brauzer

Chromium QWebEngine с вкладками, группами, AdBlock, оверлеем гайдов (Ctrl+Shift+K) и LAN UDP-рассылкой.

Мульти-Аккаунты и Изоляция

Мгновенная смена профилей с изоляцией игр, сохранений и браузера через системные ссылки (NTFS/Symlinks).

Кастомизация и Студия Дизайна

Встроенные QSS-темы, Theme Studio, кастомные цвета, фреймворк аддонов (калькулятор, монитор ресурсов, эффекты).

TV-Стриминг и Big Picture

Полноэкранный режим Big Picture (F11) под геймпад и встроенный стриминг на ТВ через Sunshine + Moonlight.

Полная Мультиязычность

Поддержка 4 языков из коробки: Русский, English, Español, Հայերեն (Armenian) с мгновенным переключением.

Авто-Обновлятор и Защита Данных

Защищенная атомарная запись JSON с бэкапами (.bak), автообновление с GitHub и локальная офлайн-документация WEB/.
