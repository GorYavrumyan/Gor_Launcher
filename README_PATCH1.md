# GOR Browser / Launcher — патч 1/4 (UI + сеть, мелкие фичи)

Это первый из 3–4 пакетов по вашему ТЗ. Пакет закрывает пункты, которые
безопасно ложатся на текущую архитектуру без переделки других модулей.

## Что внутри

Изменённые файлы (заменяют существующие один в один):

- `GOR_Brauzer/browser_groups.py`
- `GOR_Brauzer/browser_widget.py`
- `GOR_Brauzer/browser_broadcast.py`
- `core/GorLauncher.py`
- `style.qss`

## Реализованные пункты ТЗ

**1. Эмодзи для групп вкладок**
Группа теперь хранит поле `"emoji"` (авто-миграция: у старых записей без
этого поля используется 🗂️ по умолчанию, ничего вручную чинить не нужно).
В окне редактирования группы (`GroupEditDialog`) — поле ввода эмодзи + ряд
быстрых иконок для клика, как в Chrome. Эмодзи показывается в панели
«Группы» в сайдбаре, в заголовке вкладки при открытии сохранённой группы и
в заголовке свёрнутой группы («🎮 Игры (3)»).

**1. Закрепление вкладок + Ctrl+1…Ctrl+9**
Закрепление уже было реализовано (📌 в контекстном меню вкладки) — добавлены
недостающие хоткеи: `Ctrl+1`…`Ctrl+8` переключают на вкладку по позиции в
ленте (закреплённые всегда первые), `Ctrl+9` — всегда последняя вкладка, как
в Chrome/Firefox.

**2. LAN Broadcast: работа на одном ПК (loopback)**
Нашлась причина, почему это не работало: фильтр «не показывать своё же
сообщение» сравнивал `platform.node()` — имя компьютера. Из-за этого ДВА
процесса GOR Browser на одной машине глушили друг друга: второй считал
пакеты первого «своими» и просто отбрасывал их. Теперь у каждого процесса
свой `instance_id` (uuid4, генерируется при старте), фильтрация идёт строго
по нему. Дополнительно каждый пакет теперь дублируется явной отправкой на
`127.0.0.1` (без каких-либо проверок/ограничений по IP) — раньше это
зависело от того, «отражает» ли ОС широковещательный пакет обратно на
loopback, что не гарантировано на всех системах.

**4. HTTP/HTTPS индикатор**
Слева от адресной строки — иконка 🔒 (зелёная, HTTPS) или ⚠ (жёлтая, HTTP),
с тултипом-объяснением. Обновляется и при смене адреса, и при переключении
вкладок. Для служебных страниц (стартовая, file://) индикатор пустой.

**5. Ресайз боковой панели**
Сайдбар и контент браузера теперь в `QSplitter` вместо жёсткой ширины 250px
— границу можно тащить мышью (мин. 180px, макс. 520px). Показ/скрытие
сайдбара (≡, Ctrl+H) работает как раньше.

**5. Компактный верхний бар лаунчера**
Уменьшены отступы шапки (10×6 вместо дефолтных), кнопки трея/бургер-меню —
30×30 вместо 38×38, паддинги StatsLabel и SearchBar тоже уменьшены.

## Что НЕ вошло в этот пакет (будет в следующих)

- Спящие вкладки (Tab Suspender)
- Восстановление сессии при сбое
- Общий буфер обмена по LAN, синхронизация закладок по LAN
- Виджет «Сейчас в игре», авто-группа «Гайды по игре», оверлей быстрого
  поиска по вики
- Локальный менеджер паролей
- Динамический AdBlock (обновление списков с GitHub)
- Кнопка закрытия окна на кастомной панели заголовка — **нужно уточнение**:
  в текущем коде (ни в лаунчере, ни в браузере) нет собственной кастомной
  панели заголовка — везде используется стандартная рамка окна ОС. Похоже,
  речь о том, чтобы СДЕЛАТЬ кастомный title bar (frameless-окно с
  собственными кнопками свернуть/закрыть), а не поправить существующий баг
  — уточните, пожалуйста, это подразумевалось, или речь о другом месте в
  приложении (например, окне лаунчера в определённом режиме)?

## Установка

1. Сделайте резервную копию `GOR_Brauzer/`, `core/`, `style.qss`.
2. Скопируйте файлы из этого патча поверх существующих (пути совпадают:
   `GOR_Brauzer/...`, `core/GorLauncher.py`, `style.qss` в корне проекта).
3. Запустите лаунчер как обычно — новых зависимостей и миграций не требуется,
   `games_data.json` останется совместим (старые группы вкладок просто
   получат эмодзи 🗂️ по умолчанию).

## Как проверить

- **Эмодзи групп**: сайдбар браузера → «ГРУППЫ» → правый клик по группе →
  «✏️ Редактировать группу» → поле «Иконка» / ряд быстрых эмодзи.
- **Ctrl+1…9**: открыть 3+ вкладки, понажимать `Ctrl+1`, `Ctrl+2` и т.д.
- **LAN на одном ПК**: запустить два экземпляра лаунчера/браузера на одной
  машине, отправить вкладку через 📡 — второй экземпляр должен показать
  тост с уведомлением.
- **HTTP/HTTPS**: открыть `https://...` — зелёный 🔒; открыть `http://...`
  (например, `http://neverssl.com`) — жёлтый ⚠ с тултипом.
- **Ресайз сайдбара**: навести на границу между сайдбаром и контентом,
  потащить мышью.
- **Компактный topbar**: визуально сравнить высоту шапки лаунчера до/после.
