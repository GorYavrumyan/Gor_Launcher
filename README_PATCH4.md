# GOR Browser / Launcher — патч 4/4 (финальный): пароли, AdBlock, игровая интеграция

Продолжение патчей 1–3/4. Файлы этого патча включают ВСЕ накопленные
изменения из предыдущих патчей — накатывайте только их, отдельно патчи 1-3
поверх этих же файлов применять не нужно.

## Новый файл проекта

- `GOR_Brauzer/browser_passwords.py` — **новый модуль**, скопируйте его
  рядом с остальными файлами `GOR_Brauzer/` (раньше его не было).

## Новая зависимость

Менеджер паролей использует пакет `cryptography` (AES/Fernet). Установите:

```
pip install cryptography
```

`QtNetwork` (нужен для динамического AdBlock) идёт в составе самого PyQt6,
отдельно ставить не нужно.

## Что внутри

- `GOR_Brauzer/browser_widget.py` — вся связка (меню, хоткеи, вызовы)
- `GOR_Brauzer/browser_passwords.py` — менеджер паролей (новый файл)
- `GOR_Brauzer/browser_adblock.py` — динамический AdBlock
- `GOR_Brauzer/browser_constants.py` — новые настройки

## Реализованные пункты ТЗ

### 4. Локальный менеджер паролей
Новый `browser_passwords.py`: мастер-пароль → PBKDF2-HMAC-SHA256 (390 000
итераций) → ключ Fernet (AES-128-CBC + HMAC, пакет `cryptography` — именно
то, что просили в ТЗ). Мастер-пароль нигде не хранится; все записи лежат в
`passwords.vault` рядом с профилем браузера **только в зашифрованном виде**
(проверено юнит-тестом: сырой файл не содержит ни одного пароля/логина в
открытом виде). Разблокировка — на сессию, при штатном закрытии браузера
хранилище автоматически блокируется (ключ и записи стираются из памяти).
Открывается через меню ⋮ → «🔑 Менеджер паролей»: добавление/редактирование/
удаление записей, показать/скрыть пароль, генератor надёжных паролей 🎲,
копирование в буфer обмена.
⚠️ **Сознательный охват**: это ХРАНИЛИЩЕ с ручным вводом, а НЕ автозаполнение
форм на сайтах и не перехват логинов — это отдельная, значительно более
рискованная функция (риск спутать чужие формы, ложные срабатывания), в этот
патч сознательно не включена.

### 4. Динамический AdBlock
`GorAdBlockUpdater` в фоне (не блокируя UI) скачивает список блокировки с
`raw.githubusercontent.com` (по умолчанию — StevenBlack/hosts, один из самых
известных открытых hosts-листов) вместо прежнего статического набора
доменов. Понимает и hosts-формат, и простой список доменов. Результат
кэшируется в `adblock_dynamic_domains.txt` — работает даже без сети (грузит
то, что скачали в прошлый раз). Автообновление раз в настраиваемый интервал
(по умолчанию 24 ч, проверка раз в час), плюс ручное «Обновить сейчас» и
переключатель — оба в меню ⋮.

### 3. Виджет «Сейчас в игре»
Блок на стартовой странице (`start_page.html`) с иконкой, названием игры и
тремя быстрыми ссылками (📖 вики, 💬 форум, 🎮 Discord). `GameCard` при
успешном запуске игры зовёт `GorLauncher.on_game_started()`, тот пишет
`now_playing` в `games_data.json` (точечно, не трогая остальные ключи) И
сразу же живым JS-вызовом обновляет виджет на уже открытых вкладках «Главная»
(лаунчер и браузер — один процесс, поэтому это прямой вызов, без задержек).
Если для игры не заданы `wiki_url`/`forum_url`/`discord_url` — ссылки строятся
автоматически как поиск по названию игры.

### 3. Авто-группа «Гайды по [Игра]»
В контекстном меню карточки игры — новый пункт «📚 Гайды по игре (авто-группа
браузера)...»: выбираете любую уже сохранённую группу вкладок браузера
(создаются в браузере: ⋮ → «Сохранить текущую сессию как группу»). При
следующем запуске этой игры `GorLauncher.on_game_started()` автоматически
попросит браузер открыть эту группу (`GORBrowser.open_group_by_id`).

### 3. Оверлей «Быстрый поиск по вики»
`Ctrl+Shift+K` (application-wide хоткей, работает независимо от того, какой
дочерний виджет браузера в фокусе — в т.ч. веб-страница) открывает всплывающий
поисковый оверлей. Ищет по вики ТЕКУЩЕЙ игры (`site:домен запрос`, если для
игры задан `wiki_url`, иначе `"{игра} wiki {запрос}"`); если игра ещё ни разу
не запускалась — обычный поиск. Результат открывается в новой вкладке. Тот же
пункт доступен и из меню ⋮ (для тех, кто не запомнит хоткей).
⚠️ **Сознательный охват**: это хоткей **уровня приложения** (работает, пока
активно окно GOR Browser), а не перехват на уровне ОС в любой момент — для
последнего понадобились бы нативные платформенные хуки (`RegisterHotKey` на
Windows, X11-грабы на Linux) с отдельными зависимостями под каждую ОС; для
сценария «щёлкнул во время игры» обычно достаточно и этого.

## Установка

1. `pip install cryptography`
2. Скопируйте `browser_passwords.py` (НОВЫЙ файл) в `GOR_Brauzer/`.
3. Остальные файлы — поверх существующих (те же пути).
4. Никаких ручных миграций `games_data.json` не требуется.

## Как проверить

- **Пароли**: ⋮ → «🔑 Менеджер паролей» → создать мастер-пароль → добавить
  запись → перезапустить браузер → открыть менеджер снова → ввести
  правильный/неправильный мастер-пароль.
- **AdBlock**: ⋮ → «🛡️ Обновить список блокировки сейчас» → статус-строка
  покажет "+N доменов". Открыть сайт с рекламой — она должна блокироваться
  доменами из свежего списка тоже.
- **Сейчас в игре**: запустить любую игру из лаунчера → открыть/обновить
  вкладку «Главная» в браузере — вверху должен появиться блок с названием
  игры и тремя иконками-ссылками.
- **Авто-группа гайдов**: правой кнопкой по карточке игры → «📚 Гайды по
  игре...» → выбрать сохранённую группу → запустить игру → браузер должен
  сам открыть все вкладки из этой группы.
- **Wiki-оверлей**: находясь в браузере, нажать `Ctrl+Shift+K` → ввести
  запрос → Enter → открывается новая вкладка с результатами поиска.

## Итог по всем 4 патчам

Реализованы все 15 пунктов ТЗ:
1. Эмодзи для групп, pinned tabs + Ctrl+1-9, Tab Suspender, Session Restore
2. Общий буфер обмена по LAN, синхронизация закладок по LAN, фикс loopback
3. Виджет «Сейчас в игре», авто-группа гайдов, wiki-оверлей
4. Менеджер паролей, HTTP/HTTPS индикатор, динамический AdBlock
5. Кастомный title bar, resizable сайдбар, компактный topbar

Два места сознательно ограничены в охвате (см. пометки ⚠️ выше) — не потому
что забыто, а потому что полная версия (автозаполнение форм / OS-level
глобальный хоткей) требует отдельного, более объёмного и рискованного витка
разработки. Если что-то из этого нужно доделать — скажите, разберём отдельно.
