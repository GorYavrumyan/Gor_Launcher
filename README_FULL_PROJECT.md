# Полный проект — все 6 патчей уже применены

Это не очередной патч, а весь проект целиком в текущем финальном состоянии
(включая все правки из патчей 1-6). Собрал так, потому что при ручном
копировании файлов по отдельным патчам несколько раз терялись целые файлы
(сначала `core/GorLauncher.py`, потом `GOR_Brauzer/browser_constants.py`) —
проще один раз развернуть всё сразу и снять сомнения, что где-то ещё
чего-то не хватает.

## Что НЕ включено (специально)

- `GOR_Brauzer/GOR_Profile/` — это папка профиля Chromium (куки, кеш,
  история сессий движка) — 64 МБ бинарных данных, не имеет отношения к
  коду и должна остаться ВАШЕЙ существующей (со всеми вашими куки/сессиями),
  а не быть перезаписанной.
- `__pycache__/` — скомпилированные `.pyc`, Python создаст их заново сам.

## Как применить

1. **Сделайте бэкап** текущей папки `Launcher` на всякий случай.
2. Распакуйте этот архив **поверх** существующего проекта (разрешить
   перезапись всех файлов, где спросит).
3. `GOR_Brauzer/GOR_Profile/` в архиве нет — она не тронет вашу существующую.
4. Запустите:
   ```
   runtime\python.exe bridge_loader.py
   ```

## Если снова ошибка

Присылайте traceback текстом как раньше — но в этот раз, раз всё
распаковано из одного архива целиком, причина уже не будет в "забыли
скопировать файл".
